# Auditoría semanal de logging y performance

Plantilla optativa para revisar la observabilidad y el rendimiento del repositorio. Conectá sólo las fuentes que el equipo autorizó y registrá período, muestra y límites de cada conclusión.

1. Buscá errores repetidos, huecos de trazabilidad, regresiones medibles y costos de logging que oculten señales útiles.
2. Contrastá cada hallazgo con código, tests o métricas disponibles; no presentes una hipótesis como un hecho.
3. Publicá un informe o issue con evidencia reproducible, impacto, recomendación y prioridad sugerida.

La receta no toca labels de estado, slots, locks ni merges del loop.
